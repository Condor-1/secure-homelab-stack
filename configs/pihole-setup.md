# Pi-hole Setup

## Purpose

Pi-hole is used for network-wide DNS filtering and advertisement blocking

---

## Installation:-

Pi-hole was installed on Ubuntu Server using the official installation script

---

## Configuration:-

Main configuration steps included:
- Setting a static local IP address
- Configuring upstream DNS providers
- Enabling dashboard access
- Connecting client devices to use Pi-hole as DNS

---

## Features Used:-

- DNS filtering
- Advertisement blocking
- Query logging
- Dashboard monitoring

---

## Notes:-

Sensitive configuration details and IP addresses have been removed from public documentation
