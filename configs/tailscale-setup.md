# Tailscale Setup

## Purpose

Tailscale is used for secure remote access to the homelab environment without exposing ports to the public internet

---

## Configuration:-

Setup steps included:
- Installing Tailscale on Ubuntu Server
- Connecting devices to the private mesh network
- Enabling remote SSH access
- Testing secure remote connectivity

---

## Access Control

Administrative access is restricted to trusted accounts only

Client devices connected for testing purposes are limited to using the network services without access to:-
- Server administration
- Remote management
- Security dashboards
- Configuration settings

This separation helps reduce unnecessary administrative exposure and improves overall security

---

## Benefits:-

- Secure encrypted communication
- Simplified remote access
- Reduced attack surface compared to port forwarding

---

## Notes:-

Authentication details and network identifiers have been removed from public documentation
