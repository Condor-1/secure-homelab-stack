# CrowdSec Setup

## Purpose

CrowdSec is used for monitoring suspicious activity and improving server security through automated protection

---

## Features Used:-

- Threat detection
- Community-driven threat intelligence
- Monitoring suspicious access attempts
- Automated decision and protection system

---

## Custom Configuration:-

Basic custom whitelisting was configured to reduce false positives and avoid unnecessary blocking of trusted activity within the local environment

This helped improve:-
- Detection accuracy
- Stability for trusted devices
- Overall usability of the security stack

---

## Deployment Notes:-

CrowdSec was configured alongside the Ubuntu Server environment to monitor system activity and improve overall security visibility
