# Future Plans

## Improving Monitoring

One area I want to improve further is monitoring and visibility across the homelab environment. Right now, the setup is functional, but I would like to make it easier to track system health and activity over long periods of time

Possible improvements include:-
- Better monitoring dashboards
- Long-term log storage
- Improved alert visibility
- Easier tracking of system activity and uptime

---

## Backup and Recovery

Since the server runs continuously, improving backup reliability is another important goal moving forward

Future improvements may include:-
- Automated backups for important configurations
- Backup scheduling
- Easier recovery in case of service failure
- Better organization of backup data

---

## Storage and File Services

Because the system has a large amount of unused storage available, I would like to expand the homelab beyond security-related services

Possible additions include:-
- Local cloud storage using Nextcloud
- File sharing using Samba
- Secure access to files across devices
- Better storage organization and management

---

## Expanding the Environment

As I continue learning more about networking and cybersecurity, I also plan to expand the number of connected devices and services inside the homelab environment

Potential future goals include:-
- Protecting additional devices
- Improving service organization
- Experimenting with additional Linux services
- Learning more advanced monitoring and security tools

---

## Long-Term Goal

The long-term goal of this project is to continue building practical hands-on experience with:-
- Linux server administration
- Networking
- Cybersecurity concepts
- Self-hosted infrastructure
- Real-world troubleshooting and maintenance
