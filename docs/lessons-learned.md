# Lessons Learned

## Linux Server Administration

Before this project, most of my Linux usage was basic. Running a 24/7 Ubuntu Server environment helped me better understand how servers actually operate in a real-world setup instead of just inside tutorials or virtual machines

This project improved my practical experience with:-
- Understanding how servers work
- SSH-based remote administration
- Managing Linux services
- Basic network configuration and troubleshooting

---

## Networking Concepts

Working on this setup helped me understand how different networking components interact with each other inside a homelab environment

I improved my understanding of:-
- DNS filtering and request routing
- Secure remote access using VPN-based connectivity
- Local network structure
- Device connectivity and communication between services

---

## Security Awareness

This project also made me more aware of how small security decisions can affect the overall environment

Some important concepts reinforced during setup included:-
- Access control and permission separation
- Service isolation
- Threat monitoring
- Limiting unnecessary exposure to the internet
- Reducing false positives through proper configuration

---

## Documentation and Maintenance

Running a server 24/7 made me realize that maintaining infrastructure is very different from simply installing tools once and forgetting about them

This setup highlighted the importance of:-
- Keeping power usage and running costs reasonable
- Proper documentation
- Backup planning
- Monitoring service stability
- Long-term maintenance and updates
